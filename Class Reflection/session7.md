# Reflection on Today’s Class

## Topics Covered

* Java Swing and GUI
* JavaFX with Maven
* JAR, `.class` and `pom.xml`
* Packages, Artifacts and Deployment
* Git and Terminal Commands
* Character Sets and UTF-8
* Compatibility
* JUnit Testing

## What I Learned

Today I got to learn about Swing, a Java toolkit for building desktop graphical user interfaces (GUIs) like windows, buttons and menus. I also learned that javafx:run can be used in maven to run a Java FX application.

Covered key java project files: `pom.xml`, JAR files and `.class files`. I knew that .class holds compiled .bytecode, a JAR is a project packaged with Maven, and pom.xml has Maven's project configuration and dependencies.

I also got to know some basic terms like packages, artifacts, integration and deployment etc. and some useful commands like cd, git pull etc.

There was also one item of interest that I'd like to discuss: the character sets. I was able to grasp the necessity of the use of UTF-8 today and why certain older character sets remain in existence due to backward compatibility. We also talked about runtime compatibility, and why software requires the right environment in which to execute.

Lastly, I heard about JUnit, a tool to automate testing on Java.

-----

In general, today's class has helped me get a better grasp on what goes into a java program from coding to compiling, packaging, testing and deploying. The Maven, Git and JUnit concepts were very useful to me, as these are real-life tools that you can use for actual software-based projects.
