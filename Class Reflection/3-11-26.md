## Understanding Digital Images

Digital images are composed of very small portions called pixels. One pixel contains data on color or brightness and all pixels produce an entire image. I learnt how to form an image with the help of a camera to capture light and convert it to digital information.
Two key processes that are part of this are sampling and quantization. The sampling of an image breaks it up into pixels, while the quantization associates a number to each.
They will be able to describe the relationship between 2.2 Pixels, Resolution and Image Types.

Resolution is a measure of the detail that an image can have. For example, a 1920 × 1080 image has 2,073,600 pixels. I also learned that a raster image is composed of pixels and can become less crisp when enlarged, whereas a vector image doesn't lose any quality when enlarged as it is composed of mathematical shapes.

## Image Formats and Compression

There are different types of image formats for use in different situations.

- JPEG: Usually employed on photographs and is lossy.
- PNG: Supports transparency and is lossless.
- GIF: Allows simple animation.
- Bitmap (BMP): Stores bitmap information, and can be very large.
- TIFF: Often used in professional photography and scientific imaging.
- SVG: Mathematical shapes, good for logos and graphics that can be scaled up and down.

I also found out the difference between lossy and lossless compression. Lossy compression discards some information from the image to make the size smaller and lossless compression preserves everything as it was originally.

## Colour Models and Transparency

The RGB model is a combination of Red, Green and Blue to form various colors. Typically, each channel is within the range 0 - 255. For example, RGB (255, 0, 0) represents red, while (255, 255, 255) represents white.
We also talked about CMYK (printing).
The other idea was RGBA, with the extra alpha channel allowing for transparency. The value of 0 is completely transparent, and the value of 255 is completely opaque. This is helpful when you have to add logos or graphics on top of various backgrounds.
The color depth of the image is 2.5 bits.The image color depth is 2.5 bits.
The bit depth is the amount of information that can be recorded for every single pixel or colour channel. An 8-bit grayscale image can have 256 intensity levels, and a 24-bit RGB image can approximate 16.7 million colours.
In a computer, data is always represented in binary form, and pixel data is represented using 0s and 1s. A byte is four times larger than a bit, consisting of eight bits. I also got to know about MSB and LSB.
Big Endian and Little Endian describe the way that multiple bytes are stored in memory. Big Endian = most significant byte first, Little Endian = least significant byte first.

## Storage & Grayscale

Storage requirements for an image include size (width x height), number of colour channels and bit depth. For instance, if the image is 100 × 100 RGB with 24 bits per pixel, the raw image data will be approximately 30,000 bytes.
In grayscale images, there are variations of darkness and light between black and white. 0 is black and 255 is white in an 8-bit image. Grayscale images can also be obtained from a colour image with the following formula:
Gray = 0.299R + 0.587G + 0.114B
This conversion can be useful in scientific analysis, medical imaging and document processing.
Histograms are used to compare and modify images.Image histograms and image enhancement.
A histogram is a graph of the distribution of the intensity of the image's pixels. It aids in determining a picture is dark, light or lacks contrast.
Pixels that are darker tend to be represented by a histogram leaning towards the left.
A histogram towards the right indicates brighter pixels.
Broadly speaking, the wider the distribution, the larger the intensity range.
We also learned some about Brightness, Contrast and Dynamic Range. Histogram equalization adjusts the contrast by redistributing the intensity values and normalization rescales the values. Contrast stretching broadens the intensity range to see details more clearly.

## Thresholding and Segmentation

Thresholding is a technique that uses intensity of pixels to separate objects from its background. In some applications, for instance, those pixels that are smaller than a specified value may be set to black, those that are larger may be set to white.
Segmentation is the process of dividing the image into meaningful areas or objects. These methods are applicable in medicine (scans), document recognition, object detection (e.g., cell counting) in scientific images.

## Filters, Convolution and Noise Reduction

Image filters are used to enhance an image or accentuate certain aspects of an image.
Some commonly used filters include:

- Blur: Smoothens out an image.
- Sharpen: Makes things more distinct.
- Grayscale: Converts colours into shades of grey.
- Edge Detection: Detects edges in an image.
- Median Filter: Is used to clean up unwanted noise.

Convolution is another important technique. It relies on a small matrix known as a kernel which is moved across an image and then the kernel is used to compute new pixel values based on neighbouring pixels.

I also came to know about Gaussian noise and Salt and pepper noise. These unwanted variations are eliminated by using filters like median filter, gaussian smoothing.

## Introduction to ImageJ

ImageJ is an image processing and scientific analysis tool that can be particularly useful in fields such as biology, microscopy and medical research.
Some key functions include looking at histograms, adjusting brightness and contrast, using filters and converting images into greyscale. It also has functions to measure pixel values.
ROIs (Region of Interest) can be chosen so that only a certain section can be analysed.
It can measure areas, distances and intensity. Additional tools can be added using plugins.
It can be used to count cells, look at structures under a microscope and measure fluorescence intensity.
