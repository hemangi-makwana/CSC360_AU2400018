## Reflection on Today's Class

## Topics I Learned

- ASCII Trees
- Printing vs. Drawing a Tree
- Unit Testing and Acceptance Testing
- Test-Driven Development (TDD)
- Remote Computer Connection Protocols


1. ASCII Tree

I found out that ASCII tree is a text-based representation of tree data structure. Branches and connections between nodes are represented by /, \, | and - characters.

2. Printing vs. Drawing a Tree

I understood the difference between printing and drawing a tree. Printing a tree is an easy, quick, and helpful debugging tool but can be hard to decipher if the tree is large. A graphical drawing of a tree is more visually clear and more attractive, but it is more time-consuming, and more complex to implement.

3. Unit Testing vs. Acceptance Testing

I learned that a unit test tests each part of a program a method or function  while an acceptance test tests the entire system to determine if it meets the user's needs.

5. Test-Driven Development (TDD)

I learned that TDD is an approach to building software that involves writing the test first and then writing the actual code. 

First, write a test that fails, write the code to pass the test, and then enhance the code without changing the functionality.

6. Remote Computer Connection

I discovered the use of different protocols in connecting to remote computers. RDP (Remote Desktop Protocol) is used to remotely access a Windows desktop, for instance, and SSH (Secure Shell) is primarily used to remotely run a command line.

-------------------------------------------

In this class I learned about various methods of data representation, software testing and remote connection. I came to know that the decision of using text versus graphics is based on the purpose and various testing techniques are applied during various stages of software development. Additionally, by helping me to realize that testing could be part of the development process, TDD helped me to understand that.
