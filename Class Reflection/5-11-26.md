2.2 Grayscale Enhancement

This project aims to improve the contrast in grayscale images.

The enhancement method in this project includes Contrast Stretch, Histogram Equalization and Gamma Correction. All of these methods improve the image in some way. Each method alters the intensity of the pixels in a different way.

2.3 Grayscale Images

Grayscale images contain a range of shades between black and white. Within 8 bit grayscale images, pixel values range from 0 to 255.

0 = Black

255 = White

The values between are shades of grey.

If the image entered into the program is colour, it will be converted into a grayscale image. This means that only one intensity value must be processed, instead of R, G and B intensities.

2.4 Enhancement Methods

There are three enhancement methods to be considered in this project.

Contrast Stretch

Stretches the range of pixel intensities. If a majority of pixel values lie in a narrow range, then stretching to span between 0 and 255 can make the details in the image more visible.

Histogram Equalisation

Takes the histogram of the image, and redistributes the pixel intensities. This increases the contrast within the image. If there is not many different brightness values in an image, histogram equalisation can be useful.

Gamma Correction

A mathematical function is applied to change the brightness of the image. If the gamma value is low, the image becomes brighter. If the gamma value is high, the image becomes darker.

These methods can be used to improve images depending on the situation.

2.5 Lookup Table

An important aspect to this project is the Lookup Table. As there are 256 different possible pixel values in an 8 bit grayscale image, the program produces a table of 256 entries.

Each entry in the table corresponds to an intensity value which the pixel should take to apply the enhancement. Therefore, after finding the correct intensity to apply, the pixels can be adjusted according to the enhancement method.

It is easier to make the same change throughout the image.

2.6 Image Processing

Depending on the chosen enhancement method, the grayscale image is adjusted. The pixel intensity values are replaced with the new intensity.

Finally, the enhanced image is saved. It is saved in .PNG format meaning that it can be viewed. This means we can easily compare the enhanced image to the original image.

Overall, images are loaded in, converted to grayscale if required, enhanced with the chosen method and saved.

2.7 Applications

Contrast enhancement can be very useful in many areas.

Examples of this include:

- Medical Imaging – improving the visibility of features in x-rays and other grayscale scans.
- Satellite Imaging – improving the visibility of features in geography.
- Photography – improving images taken in bad light.
- Scanning Documents – making faded text easier to read.
- Research – Allows researchers to view features in images more clearly.
- Depending on how the image appears, different enhancement methods can be applied to improve it.
