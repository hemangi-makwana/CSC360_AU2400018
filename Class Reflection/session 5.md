## Class Reflection

## Topics Taught

- `paintComponent()` method
- `Graphics` class and drawing methods
- Creating a `Square` class
- Difference between a **class and an object**
- Using the `new` keyword to create objects
- Using the `super` keyword
- `super.paintComponent(g)`
- Inheritance and parent classes
- Creating and displaying shapes using Java Graphics
- Understanding the structure of a Java Graphics program

---------------------------------------------------------------------


* Learned more about how Java Graphics works and how different parts of the code work together to display shapes on the screen.
* Understood that `paintComponent()` is responsible for the actual drawing instructions, while the `Graphics` object provides the methods needed to draw different graphical elements.
* Learned the difference between a **class and an object**. A class acts as a blueprint, while an object is an actual instance created from that class.
* Understood how the `new` keyword is used to create objects, such as `new Square()`, which creates an instance of the `Square` class.
* Learned about the `super` keyword and how it allows a child class to access methods from its parent class.
* Understood why `super.paintComponent(g)` is used before adding our own drawing code. It ensures that the parent class's version of the method is executed first.
* Connecting these concepts to the creation of a square helped me understand how a simple graphical output can involve multiple Java concepts working together.
* The main takeaway from this class was that understanding **why each line of code is written** is more useful than simply memorizing the program.
* Overall, this class made Java Graphics, inheritance, objects, and methods easier for me to understand and apply in future programs.
