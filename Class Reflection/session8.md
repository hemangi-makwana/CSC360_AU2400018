# Reflection on Today's Class

## Topics Covered

* Mid-Semester Project Discussion
*  Linear Equations and Ax = b
* Determinants
* Stack and Queue
* Distance Between Two Points
* Equations and Triangles
  

Today we explored our mid-semester project as well as some crucial programming and mathematical concepts. We learnt how a linear equation such as **2x + 3y = 5** can be written in the matrix form **Ax = b**.

We also learned about the determinant, which assigns a number to a square matrix and is useful to know if a matrix has an inverse. Stacks and Queues were also discussed. In a stack, the data in the next element added to the stack is placed at the end of the list, whereas in a queue, the data in the next element added to the queue is placed at the front of the list.

We also reworked the distance formula for calculating the distance between two points and the three equations that define the sides of a triangle. As a whole, these topics enabled me to relate mathematical concepts to program and also provided a better understanding as to what we have to work on for the mid-semester project.
