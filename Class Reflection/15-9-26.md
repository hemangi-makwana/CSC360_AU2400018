## My Learning and Experience

During the session we began to explore our CSC360 project, trying to get an understanding of the things we had to create. The first discussion was on the flow of the application, and how the different screens would be connected before writing any major code.

We then created the JavaFX project, and organized the necessary files and folders. It provided us a correct basis to start the building process. I also learned a little more about the structure of a JavaFX project, and where each component of the app belongs.

## Concepts I Learned

I learned a lot about how FXML, Java classes, controllers and JavaFX components interrelate. The interface is designed using FXML, and the functionality of the interface is implemented using Java and controllers.

This was significant as we would be utilising all of these components throughout the project, not just lumping them together in one file.

## First Development Work

We set up the project, and began to design our first Splash screen. We added a simple opening page which a user sees when opening the application, including a greeting, a logo, a version and the name of the application.

We were not so concerned with the final design at this point, but rather with getting the basic structure up and running so that it would function.

## Testing and Progress

We also ran the basic javaFX structure on the initial FXML setup to ensure that the files were loading and the basic javaFX structure was functioning. This enabled us to determine if there were any issues with the setup before adding more features.

We also talked about how the splash screen would eventually be a navigation into the main application, which helped get us to think of the project as a whole app instead of a couple of screens.

## Challenges I Faced

What I didn't get was how all the various files were linked. Because the responsibilities of FXML, controllers and java classes are different, it took a little while to understand how they would communicate.

It was also during this session that I got to know the structure of the project.

## Reflection

Overall, I felt this session provided me a good beginning to the project. We started with building a solid base of the app and comprehending the various components of the system and how they would connect.

I also discovered that if you get the structure right in the beginning, it will save time later on. The splash screen is pretty simple, but it was a good way of visualising the direction of the app and provided a foundation to build on during the next sessions.
