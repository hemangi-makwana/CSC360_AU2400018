## Functionality and Features

The concept of functionality versus features was something new for me. I had no idea about the difference between the two terms before our discussion.

I was well-informed that functionality meant if the key processes or activities of the proposed application would work appropriately. On the contrary, features described the extra functionalities that a system might possess that do not necessarily have to be there for the proper working of the application.

For example, if we were to design a student record management system, the core functionalities would entail the addition and viewing of student’s records. One might be tempted to add more features to the application such as customizable themes and advanced animations solely for the sake of the presentation. However, I have come to learn that the success of my project mainly lies in the proper working of the essential processes and not with the number of extra features present in the application.

## Generics in Java

The concepts of generics was eye-opening for me as I discovered how Java allows a programmer to write classes and methods that operate with various data types. For example, generics allows a Java programmer to have a class that can hold integers without having to create specific classes for different data types.

The concept explained the use of Java collection classes such as ArrayList and ArrayList in the implementation of generic methods. From this topic, I have discovered how generics promote code reusability and save time by enabling Java to recognize classes of different data types. I desire to develop more generic classes and methods so that I can master this concept more.

## JavaFX Shape Class and Its Properties

The concepts of Java FX shapes were interesting as we got to know that JavaFX classes such as Circle, Rectangle, Line and Ellipse extend JavaFX Shape class.

This implies that Java FX shapes are related and can be operated similarly. JavaFX shapes have a set of common properties that include fill, stroke, stroke width and opacity among others. This is a good way of illustrating Java Object Oriented Programming concepts such as inheritance and polymorphism using the common properties of JavaFX shapes.

## Shape Objects vs. GraphicsContext

It was necessary to understand the differences between using shape objects and GraphicsContext for graphics programming. For instance, JavaFX shape objects take part in the scene graph, unlike GraphicsContext which makes it possible to perform low-level graphics operations.

For example, JavaFX allows the use of objects such as circles and rectangles to form graphics content. On the other hand, GraphicsContext is used with Canvas to define the graphics contents by developing algorithms to control the display. The above knowledge is fundamental in the selection of the graphics programming technique that will be used in actual applications.
